# Application of Model Predictive Control to an LQ45 Stock Portfolio Using LSTM-Based Return Prediction and Kalman Filter Noise Reduction

## Overview
This research applies Model Predictive Control (MPC) to optimize an LQ45 stock portfolio using return forecasts generated by a Long Short Term Memory (LSTM) model and refined with a Kalman Filter. The study aims to support adaptive, data-driven portfolio allocation under practical investment constraints.

## Method Summary
The proposed framework consists of three main stages:
- `LSTM` for predicting stock returns over a 22-trading-day horizon.
- `Kalman Filter` for smoothing predicted returns and reducing noise.
- `MPC` for determining portfolio weights while satisfying allocation constraints.

## Key Findings

### LSTM Return Prediction
The LSTM model was successfully developed using historical stock data with features including price, volume, historical return, technical indicators, and sentiment.

Key results:
- Highest `Directional Accuracy`: `0.585435` (`58.54%`) on `AKRA`
- Highest `Information Coefficient`: `0.091921` on `BBNI`
- Best `RMSE`: `0.012988` on `BBCA`

These results show that the LSTM model is able to capture part of the return movement pattern, although it remains limited in tracking sharp price fluctuations over the 22-day prediction horizon.

### Kalman Filter Smoothing
The Kalman Filter was applied to smooth the LSTM predictions. The changes after filtering were relatively small, indicating that the original LSTM outputs were already fairly stable.

Observed differences:
- `MEDC`: `949.90` to `949.77` (`-0.13`, `-0.014%`)
- `AKRA`: no meaningful change (`1231.58` to `1231.58`)
- `ADMR`: `+0.10` (`0.013%`)
- `MDKA`: `+0.13` (`0.009%`)
- `BBNI`: `+0.07` (`0.002%`)

This indicates that the Kalman Filter acted mainly as a refinement step rather than a technique that significantly altered prediction direction or magnitude.

### MPC Portfolio Allocation
MPC was successfully implemented to allocate portfolio weights while satisfying investment constraints, including:
- total portfolio weight equals `100%`
- non-negative asset weights
- maximum allocation limits per stock to avoid excessive concentration

The resulting portfolio consists of `MEDC`, `AKRA`, `ADMR`, `MDKA`, and `BBNI`, with weights ranging from `18.62%` to `20.94%`, equivalent to approximately `IDR 18.6 million` to `IDR 20.9 million` from a total capital of `IDR 100 million`.

Portfolio performance summary:
- Expected return range: `-7.99%` to `2.16%`
- Realized return range: `-17.57%` to `12.93%`

These findings confirm that MPC can satisfy investment constraints while balancing expected return and risk, making it a practical approach for dynamic and rational portfolio management.

## Conclusion
This study shows that the combination of `LSTM`, `Kalman Filter`, and `MPC` can be effectively applied to return prediction and portfolio allocation for LQ45 stocks. LSTM captures part of the return dynamics, Kalman Filter improves estimate smoothness, and MPC provides feasible and adaptive portfolio decisions under investment constraints.
